Slide 20

The Challenge — Empty layout

Fleet managers and operators face key challenges in battery monitoring across varied equipment and usage patterns:

  • Extended data gaps: Trucks that haven't transmitted data for more than 24 hours create blank, uninformative charts
  • Weekend/off-hours: Equipment downtime appears as "missing" data Monday mornings
  • 30 + day inactivity: Completely empty charts across all time ranges
  • Inconsistent visuals: Different chart styles per time view create confusion about data vs. equipment status

Slide 21

The Challenge — Short intervals

When does this situation occur?

  • Micro-operations: Equipment operations lasting only seconds or minutes created numerous tiny data points
  • Scale-dependent readability: In 24-hour views short intervals were interpretable, but became overwhelming in 7-day and 30-day views
  • Pattern interference: Brief operational spikes made it difficult to identify meaningful usage trends and battery performance patterns

Slide 22

The Challenge — Long intervals

Fleet managers needed efficient navigation through extended operational periods and historical data investigation:

  • Pin Mode operations: Equipment left in operation without logout
  • Historical analysis: Users want to examine SoC changes on previous days but lack intuitive navigation
  • Extended pattern investigation: Need to analyze trends over longer periods while maintaining access to detail

Slide 23

SoC chart — Conclusion

I implemented an interactive zoom tool that allows users to dynamically investigate micro-operations, filter noise for pattern recognition, and navigate historical data

Results and Impact

  • Empty Layout: Confusion eliminated through contextual messaging and consistent visuals
  • Short Intervals: Granular detail accessible and noise filtered for clear trend analysis
  • Long Intervals: Efficient historical navigation and extended range access facilitate comprehensive investigations

Success Metrics

  • Reduction in support tickets related to chart interpretation
  • Increased user engagement with detailed battery performance analysis
  • Improved maintenance scheduling accuracy based on clearer insights
