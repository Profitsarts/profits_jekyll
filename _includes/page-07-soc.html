The Challenge

  • Fleet managers and operators face key challenges in battery monitoring across varied equipment and usage patterns.
  • Extended data gaps: Trucks that haven't transmitted data for more than 24 hours create blank, uninformative charts
  • Weekend/off-hours: Equipment downtime appears as "missing" data Monday mornings
  • 30+ day inactivity: Completely empty charts across all time ranges
  • Inconsistent visuals: Different chart styles per time view create confusion about data vs. equipment status

User Research Insights

  • Based on user testing and stakeholder interviews, we identified key pain points:
  • "I can't tell if the truck is broken or just not sending data"
    Uncertainty about equipment status versus data transmission issues
  • "The charts look completely different between time ranges, it's confusing"
    Visual inconsistency created cognitive load
  • "When I check on Monday, everything looks empty, but I don't know if that's normal"
    Lack of context about expected operational patterns
